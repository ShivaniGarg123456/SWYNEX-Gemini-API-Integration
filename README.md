# SWYNEX Gemini API Integration

A prototype developed as part of the **SWYNEX Technologies Internship – Task 2: Model/API Integration**.

This project integrates the **Google Gemini API** into an AI-based contract compliance analysis workflow.

## Project Overview

The prototype analyzes a sample contract and checks important contract categories such as:

* Payment
* Termination
* Intellectual Property
* Confidentiality
* Liability

For each category, Gemini identifies whether the information is **Present, Missing, or Unclear**, along with a short explanation.

## AI Model

* **Model:** Gemini 3.6 Flash
* **API:** Google Gemini API
* **Language:** Python
* **SDK:** Google GenAI SDK

## How It Works

```text
Contract Text
      ↓
Prompt sent to Gemini API
      ↓
Gemini analyzes important contract categories
      ↓
Contract Audit
      ↓
Present / Missing / Unclear + Explanation
```

## Example Input

The prototype uses a sample freelance service agreement containing clauses related to payment, termination, intellectual property, confidentiality, and liability.

## Example Output

The system produces a contract audit such as:

```text
Payment: Present
Termination: Present
Intellectual Property: Present
Confidentiality: Present
Liability: Unclear
```

Each category also includes a short explanation generated by Gemini.

## Setup

Install the required Google GenAI SDK:

```bash
python -m pip install -U google-genai
```

Set your Gemini API key as an environment variable:

```text
GEMINI_API_KEY=your_api_key
```

Then run:

```bash
python Task2_contract_analyzer.py
```

## Security

The API key is stored as an environment variable and is **not included in the source code or GitHub repository**.

Never commit or share your API key publicly.

## Limitations

This prototype is intended for **informational contract analysis only**.

It does not:

* provide legal advice
* determine whether a contract is legally valid or enforceable
* replace professional legal review

The quality of the analysis depends on the contract text, prompt, and AI model output.
